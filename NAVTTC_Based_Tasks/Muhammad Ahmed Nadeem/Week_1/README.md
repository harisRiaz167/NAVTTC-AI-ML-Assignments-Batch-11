## Overview

This directory contains the solutions for **Week 1 Assignments**. The focus of this week was establishing core Python programming concepts including numeric data types, input/output operations, built-in mathematical modules, and basic geometric/algebraic algorithms.

---

## Tasks Summary

| Task # | Title | Description | Techniques / Modules |
|---|---|---|---|
| **Task 1** | Sum of Real Numbers | Adds two floating-point numbers (`1.5` and `6.3`) and formats the result. | Dynamic typing, arithmetic addition (`+`) |
| **Task 2** | User Input Addition | Captures numbers via `input()`, casts to `float`, and computes sum. | `input()`, type casting `float()` |
| **Task 3** | Square Root Calculation | Computes the principal square root of a real positive number. | Built-in `math.sqrt()` |
| **Task 4** | Complex Number Square Root | Finds the square root of complex number $1 + 2j$. | Built-in `cmath.sqrt()` |
| **Task 5** | Celsius to Fahrenheit | Converts $37.5^\circ\text{C}$ to Fahrenheit: $F = (C \times 9/5) + 32$. | Arithmetic formulas & float operations |
| **Task 6** | Triangle Area (Heron's Formula) | Calculates area for sides $a=5, b=6, c=7$ using semi-perimeter and Heron's formula. | `math.sqrt()`, algebraic geometry |
| **Task 7** | Quadratic Equation Solver | Computes roots of $ax^2 + bx + c = 0$ ($a=1, b=5, c=6$) using quadratic formula. | `cmath.sqrt()`, discriminant calculation |
| **Task 8** | Kilometers to Miles Converter | Converts distance in kilometers to miles using factor $0.621371$. | Unit conversion, interactive input |
