## Overview

This module covers numerical computing foundations using NumPy. Topics include multi-dimensional array creation, coordinate indexing, slicing, memory optimization (Copy vs View), data type management, reshaping, and searching.

---

## Tasks Summary

| Task # | Title | Key Concepts | Implementation |
|---|---|---|---|
| **Task 1** | Multidimensional Array Creation | 1D/2D arrays, `zeros`, `ones`, `arange`, `linspace` | Multidimensional grid and vector initialization |
| **Task 2** | Coordinate Indexing & Slicing | Direct access, row/column slicing, multi-axis slicing | Feature matrix extraction and sub-array access |
| **Task 3** | Data Types & Type Casting | `dtype` inspection, explicit conversion with `astype` | Float to Int32 and Boolean conversions |
| **Task 4** | Memory Mechanics: Copy vs View | Shallow reference (`view`) vs independent allocation (`copy`) | Mutation testing and `.base` verification |
| **Task 5** | Reshaping & Boolean Indexing | Dimension transformation (`reshape`, `flatten`, `where`) | 1D vector to 2D matrix transformation & threshold filter |
